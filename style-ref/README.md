## 排版与留白

- 个人主页和博客用浅色纸面托住深墨色文字。标题用 Source Serif 4 与 Noto Serif SC，按钮和辅助信息用 Noto Sans SC。像素风景在天空和文字之间留出空域。
- 笔记站首页用 Georgia 衬线标题、无衬线辅助文字和大块留白。猫猫周围的淡蓝与浅紫随深浅主题调整，标题的蓝紫渐变从浅色模式的 `#365ba1 → #805e98` 换到深色模式的 `#a9c6ff → #dcb8ee`。
