# Aumnertic 风格参考

Aumnertic 是公开署名，Aum 用于打招呼和自我介绍。这里记录在数据库基础设施、Rust 和系统软件方向的学习，也写开源实践、个人项目和生活随笔。GitHub 主页上的一句话是 “make it fast & keep it small.” [GitHub 主页](../README.md)

首页和博客用四季像素风景、手写 A 和深墨浅纸建立识别。首页的书房、博客的头像和笔记站的翻页插画里是同一只猫，灰白虎斑、蓝眼睛、蓝色围巾和金色四瓣花章。笔记站给猫和标题留出大块空白，进入正文后以排版、侧栏和细线组织信息。
